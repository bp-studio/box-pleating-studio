
# Tools

This section contains tools for assisting debugging issues.

- `optimizerBench`: benchmarking the optimizer on a folder of designs.
  See [optimizerBench/README.md](optimizerBench/README.md).
- `polyBool`: visualizing the polygon boolean operations. Run with `pnpm tools`.
- `renderCheck`: checking the rendering of a large number of random layouts.
  See [renderCheck/README.md](renderCheck/README.md).
