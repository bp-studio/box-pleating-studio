
## Version 0.8.0

🔥 Highlights:
- Cut, copy, and paste branches in the tree structure view, also across projects.
- New "Check layout" tool, which diagnoses common layout issues (invalid overlaps, missing stretch patterns, uncovered regions, broken ridges, and unnatural rivers) and gives suggestions for fixing them. See the [user manual](https://bp-studio.github.io/manual.html#health-check) for details.
- CP exporting now generates a "generic CP" with mountain/valley assignments, which is a much better starting point for further editing. For `.cp` format, hinges can be exported as auxiliary lines, valley folds, or omitted.
- The layout optimizer has been greatly improved:<ul>
  <li>The fitting stage is rewritten as a constraint satisfaction search instead of running the nonlinear solver for each flap. It now takes only milliseconds even for designs with a hundred flaps, and typically results in equal or smaller sheets.</li>
  <li>A new tidying stage rearranges the flaps to make the layout as neat as possible, with straighter rivers and fewer overlaps to be resolved by stretch patterns.</li>
  </ul>
- More stretch patterns are supported, including many patterns involving four flaps and nested relays.

🐛 Bug fixes:
- The contour algorithm has been thoroughly reviewed from the ground up. Every step is re-examined and verified, leading to a more consistent and reliable approach that fixes many edge cases, especially for rivers wrapping around overlapping flaps. A large number of new test cases are also added to ensure an unprecedented level of reliability.
- Fix rare rendering errors of river ridges.

💪 Improvements:
- Rotating and flipping can now be applied locally to the selected vertices or flaps.
- New automated stress testing for rendering: thousands of compact random layouts are generated and checked for rendering problems (such as overlapping regions or ridges crossing the hinges), and each problem found is reduced to a minimal case for investigation. Many subtle bugs have been found and fixed this way, making the whole algorithm much more robust.
- Testing is now more efficient using [Rstest](https://rstest.rs/).
- Improve URL shortening in project sharing.
